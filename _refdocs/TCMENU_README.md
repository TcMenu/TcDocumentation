## Summary 

This library is part of the TcMenu project.

TcMenu is a powerful menu system for Arduino, PicoSDK, ESP32-IDF, STM32Cube, and mbed. It provides a simple and flexible
way to create menus and handle user input. It supports various types of menu items, including buttons, sliders, and
text fields. TcMenu is highly customizable and can be easily integrated into existing projects.

This is the reference documentation, you can also find more documentation on the main site.
